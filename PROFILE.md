# OnTopX402

A single money-ranked public link leaderboard where rank is decided by the amount paid in USDC via the x402 protocol. Submit a link, description, and amount to appear at the position that amount buys; bids stack. No accounts or API keys — reads are free, paid writes settle via x402 micropayments on Base and Solana.

## APIs

- **OnTopX402 API** — REST API for reading the money-ranked link leaderboard, looking up individual links, and submitting paid bids to get listed or climb the board. Paid writes are gated by x402 USDC micropayments; reads are free but rate-limited. (`https://ontopx402.com`)

> REST API with public OpenAPI 3.1 contract (3 endpoints: GET /api/leaderboard, GET /api/entry, POST /api/bid) and an llms.txt. Auth is unconventional — no accounts/keys; paid writes use x402/USDC micropayments on Base (facilitator https://api.cdp.coinbase.com/platform/v2/x402) and Solana. No hosted MCP server and no published agent skills were found (/mcp and /.well-known/mcp.json are not referenced). The service supports x402 'bazaar' agent discovery via the OpenAPI PaymentRequired extensions block, but this is not an MCP server. Agent payment tools (AgentCash, AWAL, Pay.sh, Poncho) are referenced in the llms.txt as discovery/payment clients. Contact: info@ontopx402.com.
